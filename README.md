# warbler-demo

Warbler is a virtual analog software synthesizer made with C++ and JUCE. It is closed source, but I expect to make it downloadable within the next couple of months (pending some more testing and bug fixes). Warbler has 3 oscillators, 2 LFOs, a vintage-style ladder filter, a custom preset browser, and a few other parameters that I thought would be fun to play around with.
